# Fineract loans (trimmed copy)

This repository is a trimmed copy of [Apache Fineract](https://github.com/apache/fineract) 1.15.0, at commit `d5636847ac556c30b437254c353f05526d172b97`.

It keeps only the loan modules:

- `fineract-core`
- `fineract-loan`
- `fineract-progressive-loan`
- `fineract-provider`

Everything else from the original repository is removed. The code in these modules is unchanged. It is used to test policy enforcement on a real lending system.
